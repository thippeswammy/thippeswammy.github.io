# NeetCodeProblems

Java and Kotlin solutions for NeetCode and coding interview problems.

## About

This repository contains solutions to various coding interview and DSA problems from NeetCode, LeetCode, and other platforms.
The project is mainly focused on improving problem-solving skills and preparing for technical interviews.

## Features

* Solutions in Java and Kotlin
* Data Structures and Algorithms practice
* Competitive programming problems
* Interview preparation questions
* Clean and simple implementations

## Technologies Used

* Java
* Kotlin

## Topics Covered

* Arrays
* Strings
* Linked Lists
* Trees
* Graphs
* Dynamic Programming
* Recursion
* Searching and Sorting
* Stack and Queue
* Binary Search
* Greedy Algorithms

## Purpose

This repository is created for learning, practicing DSA, and preparing for coding interviews.
